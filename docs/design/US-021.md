# US-021 — Écran « Dossiers » (liste) et création d'un dossier

**Carte** : `t_bcac06b9` · **Branche** : `agent/us-021` · **Maquettes** : aucune planche dédiée ; références `direction-b/dossier.html` (carte blanche, pastille, titre) et `direction-b/accueil.html` (marges 20 px, typographie 800).
**Périmètre** : couche visuelle et états de `/dossiers` — écran de liste, état vide, dialogue « Nouveau dossier ». Le détail d'un dossier (`/dossiers/:id`) est US-022. Aucun code, aucune PR.

## 1. Parcours

| Départ | Action | Arrivée |
| --- | --- | --- |
| Écran connecté (`/`, `/depenses`…) | onglet « Dossiers » de la barre de navigation | **Écran 1**, `/dossiers` |
| **Écran 1** | clic sur une carte | `/dossiers/{id}` (US-022) |
| **Écran 1** | clic « Nouveau dossier » | **Écran 2**, dialogue ouvert, focus dans « Titre » |
| **Écran 2** | « Créer » avec titre valide | `apiPost("/v1/notes")` (`POST /api/v1/notes`) → `/dossiers/{id}` du dossier renvoyé |
| **Écran 2** | « Annuler » ou `Escape` | fermeture, focus rendu au bouton déclencheur, écran 1 inchangé |
| **Écran 1** | `GET /api/v1/notes` en erreur | écran 1 + alerte + « Réessayer » |

Deux écrans : **1. liste** (chargement, vide, nominal, erreur), **2. dialogue** (repos, erreur de validation, envoi, erreur serveur). La route `/dossiers` cesse de rendre `PageBientotDisponible` ; elle est identique pour les rôles `utilisateur`, `valideur` et `admin` (aucun contrôle de rôle côté client).

## 5. Textes dérivés (aucune chaîne vide, jamais `NaN`)

| Donnée | Règle de rendu |
| --- | --- |
| Période, `derniere_depense_le = "2026-11-17"` | « **Novembre 2026** » : découper `AAAA-MM-JJ` (`split("-")`), construire `Date.UTC(a, m-1, j)`, formater avec `Intl.DateTimeFormat("fr-FR", { timeZone: "UTC", month: "long", year: "numeric" })`, puis capitale initiale. Ne **jamais** passer par `new Date(dateIso)` ni `getMonth()` locaux : la date est civile, aucun décalage d'un jour (équivalent au mois calendaire `Europe/Paris`, insensible au fuseau de la machine). |
| Période, `derniere_depense_le = null` | « Aucune dépense » |
| Nombre | `0` → « 0 dépense » · `1` → « 1 dépense » · `n` → « n dépenses » |
| Total | `formatMontant(total_centimes)` — `0` → « 0,00 € » (espace insécable de `Intl`), `tabular-nums` |

## 7. Écran 2 — dialogue « Nouveau dossier »

- **Overlay** : `fixed inset-0 z-50 bg-[rgba(26,26,46,0.45)]` (teinte du texte principal, aucun jeton nouveau), contenu cliquable au clic.
- **Panneau** : mobile `< 640 px` → feuille basse `fixed inset-x-0 bottom-0 rounded-t-[26px] p-5 pb-8` ; ≥ 640 px → boîte centrée dans un conteneur `px-5` (`mx-auto w-full max-w-[420px] rounded-[26px] p-5`, `my-auto`). Fond `var(--card)`, ombre `var(--ombre-carte)`, `role="dialog" aria-modal="true" aria-labelledby="titre-nouveau-dossier"`.
- **Contenu** : `h2` « Nouveau dossier » (20 px, 800, `id="titre-nouveau-dossier"`) ; `<label for="titre-dossier">` « Titre » (13 px, 700) ; `<input id="titre-dossier" type="text" autoComplete="off">` `h-[52px] w-full rounded-[18px] bg-[var(--secondary)] px-4 text-[15px]`, **focalisé à l'ouverture**, pas d'attribut `required` ni `maxLength` (la validation maison doit pouvoir produire ses messages) ; pas de compteur de caractères.
- **Boutons** (ordre DOM et visuel : « Annuler » puis « Créer ») : grille 2 colonnes `gap-2.5`, hauteur 52 px, rayon 18 px. « Annuler » : fond `var(--secondary)`, texte `var(--foreground)`, graisse 700. « Créer » : primaire, texte blanc, graisse 700.
- **Focus** : à l'ouverture, focus dans le champ ; `Tab` boucle sur champ → « Annuler » → « Créer » ; `Escape` ferme (sauf envoi en cours) ; à la fermeture, focus rendu au bouton « Nouveau dossier » ; clic sur l'overlay = « Annuler ».

| Validation (au clic « Créer ») | Message exact, `role="alert"` sous le champ | Réseau |
| --- | --- | --- |
| `titre.trim()` vide | « Le libellé est requis. » | aucun appel |
| `titre.trim().length > 200` | « Le libellé est trop long (200 caractères maximum). » | aucun appel |
| valide | — | `POST /api/v1/notes` avec `{ "libelle": "<titre élagué>" }` |

Le champ en erreur porte `aria-invalid="true"` et `aria-describedby` vers le paragraphe d'erreur (13 px, 600, `var(--erreur-texte)`).

| État du dialogue | Rendu |
| --- | --- |
| Repos | « Créer » actif, aucun message |
| Envoi | « Créer » devient « **Création…** », désactivé + `aria-busy="true"` ; champ et « Annuler » désactivés ; `Escape` neutralisé |
| 422 serveur | Le message du serveur (`erreursDeDetail(detail)` pour `libelle`, sinon message global) s'affiche dans le bloc `role="alert"` sous le champ ; dialogue ouvert, titre conservé, « Créer » réactivé |
| 5xx ou réseau | Même emplacement, message de l'`ApiError` (« Serveur injoignable. Vérifiez votre connexion. » le cas échéant) ; dialogue ouvert, titre conservé, bouton réactivé |
| Succès | Dialogue démonté, navigation vers `/dossiers/{note.id}` |
| 401 | `onSessionExpiree()` → connexion, pas de retentative |

## 8. Accessibilité et mobile

- Ordre de focus : `h1` (au montage) → bouton « Nouveau dossier » → cartes de la liste (liens) → barre de navigation. Aucun `tabIndex` positif.
- `role="alert"` sur toutes les erreurs ; `aria-busy` sur la section et le bouton pendant les chargements.
- Contrastes mesurés : titre `#1A1A2E`/blanc 17,06:1 ; secondaire `#565A73`/blanc 6,76:1 (6,18:1 sur `#F3F4FF`) ; bouton primaire blanc/`#5B3DF5` 6,12:1 ; erreur `#9F1239`/`#FFE4E6` 6,68:1 ; pastilles 5,69:1 à 8,44:1.
- Cibles ≥ 44 px (carte 88 px, boutons 52 px, pastille non interactive), focus visible 2 px primaire décalé de 2 px, `prefers-reduced-motion` respecté (aucune animation hors `active:opacity-90`).
- Mobile d'abord à 320 px : aucun défilement horizontal, titre tronqué à 2 lignes, bouton pleine largeur, feuille basse au-dessus de la barre de navigation.
- Interdits rappelés : aucun emoji, aucun dégradé, aucune bordure colorée latérale, aucune couleur hors `AGENTS.md`.

## 9. Limites

- Ne pas toucher aux maquettes existantes (`accueil.html`, `saisie.html`, `dossier.html`), à `AGENTS.md` ni à `index.css`.
- Hors périmètre : détail/édition/soumission d'un dossier (US-022), suppression, renommage, pagination, recherche, filtrage, historique.
- La route `/dossiers/:id` n'existe pas encore : la navigation vise bien ce chemin (vérifié par le test Vitest) ; en attendant US-022, la route générique `*` renvoie vers `/`.
