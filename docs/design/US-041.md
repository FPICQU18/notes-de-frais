# US-041 — Maquettes HTML de la version bureau (≥ 1024 px)

**Carte** : `t_db3f2daa` · **Branche** : `agent/us-041` · **Maquettes** : 4 fichiers HTML autonomes dans `direction-b/`
**Périmètre** : couche visuelle et états des écrans bureau (≥ 1024 px) pour les US-042 à US-045. Aucun code, aucun contrat d'API, `AGENTS.md` inchangé.

## 1. Parcours

| Départ | Action | Arrivée |
| --- | --- | --- |
| Écran connecté (mobile) | élargir la fenêtre à ≥ 1024 px | **Écran bureau** : barre latérale gauche fixe, zone de contenu centrée (max 1100 px) |
| **Écran bureau** | clic sur « Dépenses » dans la barre latérale | **Écran 1** : formulaire de dépense centré (640 px) |
| **Écran bureau** | clic sur « Dossiers » dans la barre latérale | **Écran 2** : liste des dossiers en tableau triable |
| **Écran bureau** | clic sur « Validation » dans la barre latérale | **Écran 3** : maître-détail (file à gauche, détail à droite) |
| **Écran 3** | clic sur un dossier dans la file | Panneau détail à droite mis à jour |
| **Écran 3** | clic sur « Valider » / « Refuser » | Surcouche de confirmation → décision appliquée → retour à la file, dossier suivant sélectionné |
| **Écran bureau** | clic sur « Comptes » dans la barre latérale (rôle admin) | **Écran 4** : gestion des comptes en tableau |

Quatre écrans : **1. mise en page + formulaire**, **2. dossiers**, **3. validation maître-détail**, **4. comptes**. Les rôles ne sont jamais contrôlés côté client : l'affichage s'adapte, le serveur refuse (403 → message du serveur dans l'alerte, sans « Réessayer » ; 401 → écran de connexion).

- Pastille de statut : `inline-flex h-6 items-center rounded-full px-2.5 text-[12px] font-bold whitespace-nowrap`, libellé texte + `--statut-<statut>-fond/texte` ; le libellé porte l'information.
